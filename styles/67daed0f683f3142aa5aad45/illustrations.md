# Overview

Yandex Travel uses playful campaign artwork alongside photography: simple 3D travel objects, mascots, and bold geometric fields.

# Visual Style

Use softly modeled toy-like objects with clean silhouettes, minimal materials, and a slightly surreal editorial character.

# Composition

Center one object or small travel set on a high-contrast field, leaving a clear block for a short headline and action.

# Color

Anchor campaigns in violet and yellow, with coral, orange, or pale blue used as one supporting field.

# Usage

Use illustration for seasonal campaigns, category identity, summaries, and rewards; keep listings and destinations photographic. New art should remain harmonious with `ui.md`.
