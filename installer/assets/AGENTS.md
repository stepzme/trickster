# Trickster: процесс разработки iOS-приложения

При создании или существенном изменении приложения:

1. Прочитай `trickster/workflow/master-prompt.md` и последовательно выполни все применимые этапы. `ux.md` и `ios.md` действуют сквозным образом.
2. SCRN MCP обязателен: выбери релевантную категорию из `scrn-categories.md`, просмотри реальные изображения и сохрани доказательства.
3. Если scope неполон, восстанови локально реализуемый функциональный baseline по приложениям той же категории; не добавляй незапрошенную внешнюю инфраструктуру.
4. Выбери один `DESIGN.md`, сообщи пользователю выбор и дождись подтверждения до проектирования UI. Не используй случайный дизайн и не создавай несколько концепций.
5. Создай артефакты run-id, делегируй только ограниченные задачи и самостоятельно проверь интегрированную сборку в Simulator.
6. Для нового приложения после реализации экранов создай одну app icon по просмотренным Logoinspo-референсам, проверь её в финальной сборке, затем после приёмки создай один ASO-комплект из реальных экранов.
7. Недоступные инструменты, MCP или проверки помечай `UNVERIFIED`. Не подменяй отсутствующие доказательства предположениями.

Не изменяй критерии, выбранный DESIGN.md или референсы только ради получения PASS.
