# Overview

FocusPomo connects a focus timer, breaks, tags, tracking, statistics, calendar, goals, and app blocking.

# Navigation

Timer is primary; summary, calendar, and settings remain one step away.

# Core Flows

## Complete a focus cycle

1. Choose a tag and start focus.
2. Track remaining time.
3. Complete or interrupt explicitly.
4. Start a break and review progress.

# Interaction Patterns

- Keep current state and remaining time visible.
- Confirm interruption.
- Record tag and duration accurately.
- Celebrate after completion, not during focus.
