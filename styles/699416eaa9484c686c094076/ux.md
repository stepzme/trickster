# Overview

Cian supports property discovery, comparison, contact, favorites, alerts, messaging, listing creation, owner tools, and wallet operations.

# Navigation

Home, Search, Favorites, Messages, and Office form the base. Map, results, listing detail, and creation preserve their own task context.

# Core Flows

## Find a property

1. Set deal type, property, location, rooms, and filters.
2. Browse map or list and save the search.
3. Open photos, attributes, description, price history, and neighborhood context.
4. Compare similar listings, favorite, add note, call, or message.

## Publish a listing

1. Enter location, property details, media, features, description, price, and terms; review placement options, pay when required, and publish or save a draft.

# Interaction Patterns

- Preserve filter state across map and list.
- Keep price and core attributes comparable.
- Make owner or agent contact explicit.
- Confirm paid publication and deletion.
- Separate buyer alerts from owner statistics.
