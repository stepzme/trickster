# Overview

A generative-video social product. The experience moves from atmospheric onboarding into a media-first feed, then uses a prompt composer and draft workflow for creation.

# Navigation

A five-item primary navigation covers feed, search, create, notifications, and profile. Creation is directly available from primary navigation. Immersive onboarding temporarily removes navigation; publishing and editing use focused layers with close and overflow actions.

# Core Flows

## Enter the product

1. Continue with an existing ChatGPT identity or choose another account.
2. Review profile presentation and add a profile image.
3. Read the content advisory and begin viewing.

## Browse and respond to video

1. Swipe through video.
2. Use the controls for likes, comments, reactions, and sharing.
3. Open creator context from the avatar or caption without leaving the media-first hierarchy.

## Create and publish a video

1. Open the create action.
2. Choose cameos and write a natural-language prompt.
3. Submit generation and review the result in Drafts.
4. Edit the video or caption, then publish.
