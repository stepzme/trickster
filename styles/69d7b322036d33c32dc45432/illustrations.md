# Overview

Yandex Realty uses soft toy-like property objects and simple spot graphics to make service entry points approachable without competing with listing photography.

# Visual Style

Model homes, keys, furniture, calendars, boxes, and service symbols as simplified rounded 3D objects with matte or translucent materials. Small onboarding spots may use flat bold shapes with black outlines.

# Composition

- Use one object or compact cluster centered inside a rounded tile.
- Keep shallow perspective and a soft grounding shadow.
- Separate decorative objects from photographic listing content.

# Color and Materials

Lead with Yandex yellow, then add restrained cyan, violet, mint, beige, and charcoal accents on white.

# Variants and States

Use for home shortcuts, services, posting choices, onboarding, alerts, and empty states. Use real photography for properties and real maps for location.

# Avoid

- Do not replace the documented image language with unrelated stock art, arbitrary symbols, or a denser composition.
