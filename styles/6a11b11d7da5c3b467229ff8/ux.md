# Overview

Grok supports text and voice conversation, Ask and Imagine modes, connectors, files and camera, generated images and animation, tasks, companions, history, and extensive settings.

# Navigation

A minimal top shell switches Ask and Imagine and opens the main menu. The current conversation occupies one column while the composer remains persistent.

# Core Flows

## Ask and refine

1. Enter a prompt, choose speed or model, attach a connector or file if needed, send, observe thoughts and generation, then copy, listen, rate, share, retry, or continue.

## Generate media

1. Switch to Imagine or request an image, review the generated asset, change settings or animate, save or select results, and refine through follow-up prompts.

# Interaction Patterns

Tool choices appear as tool choices, the composer expands for text, active generation exposes stop, answers remain unboxed, and media actions stay attached to their result.

# System Access Timing

No system-access timing or denial-recovery behavior was documented in the reviewed source.
