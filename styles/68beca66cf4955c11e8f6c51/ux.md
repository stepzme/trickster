# Overview

Stocks is a, list-led market utility for watchlists, quote details, charts, widgets, and financial news.

# Navigation

- A watchlist screen combines search, symbols, and Business News.
- Selecting a symbol opens a quote sheet with time-range controls, metrics, news, and a contextual overflow menu.

# Core Flows

## Manage a watchlist

1. Search or open the watchlist options visible in the inspected screens.
2. Add a named watchlist or assign a symbol to an existing one.
3. Reorder or remove symbols from edit mode.

## Inspect a quote

1. Select a symbol from the list or ticker strip.
2. Switch chart ranges from intraday to all-time.
3. Review open, high, low, volume, market-cap, and related news.

## Use a widget

1. Choose a quote, chart, or multi-symbol widget layout.
2. Edit the widget's displayed symbols from its configuration surface.

# Interaction Patterns

- Symbol selection opens a quote sheet without losing the watchlist context.
- Time-range controls update the current chart; edit mode handles reordering and removal.
