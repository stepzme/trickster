# Overview

Simply uses glossy 3D promotional objects to represent cards, shopping, travel, entertainment, and partner benefits. The language belongs to promotions rather than operational finance screens.

# Visual Style

- Rounded glossy 3D objects with soft reflections.
- Violet, magenta, yellow, and blue gradients.
- Simplified bags, cards, tickets, travel, and service symbols.
- Clean white or gradient card backgrounds.

# Composition

- Pair one large object with a short percentage or benefit line.
- Anchor the object to a lower or side edge.
- Keep enough negative space for the numeric offer.
- Avoid detailed narrative scenes.

# Color and Materials

- Use violet and magenta for the object mass.
- Use yellow to connect with the wallet brand.
- Add blue or coral only as supporting material.
- Keep operational status colors out of the art.

# Variants and States

- Use in Promotions, benefit cards, installment banners, and service discovery.
- Keep payments, transfer forms, history, and profile rows illustration-free.
- Match each object to the benefit it represents.
- Create original objects rather than copying existing campaign assets.

# Avoid

Do not introduce an unrelated illustration style or substitute decorative symbols for source-supported imagery.
