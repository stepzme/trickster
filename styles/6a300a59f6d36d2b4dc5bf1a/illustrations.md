# Overview

Janymda uses soft 3D object scenes in onboarding and rounded miniature objects for service icons.

# Visual Style

Matte white or pastel objects, softly extruded with diffuse shadows and gentle blue-purple-pink lighting. Forms are simplified, friendly, and immediately recognizable.

# Composition

Onboarding groups four to six floating objects in an open central cluster. Service icons reduce the same language to one object on a faint tinted tile.

# Color

Keep object bodies pale and let blue, violet, pink, yellow, and teal gradients provide category distinction. Avoid dark outlines.

# Usage

Use large scenes for broad benefit statements and miniatures for service categories. Any new illustration should reuse the UI gradient palette and soft rounded materials so it feels native to the product.
