# Overview

Illustration makes tariffs, services, entertainment, and AI feel approachable while account and security tasks remain functional.

# Visual Style

- Playful 3D objects, stylized characters, and editorial photography.
- Beeline yellow, black, white, pale lavender, and occasional orange.
- Rounded toy-like phones, coins, planes, packages, and service symbols.
- Airy cool-gray backgrounds with soft shadow.

# Composition

Place one main object or character in a large promo card, or a compact object cluster inside a story tile. Leave clear space for lowercase headline and yellow CTA.

# Color and Materials

Use the palette relationships explicitly described in the visual language and `ui.md`; no additional material system was documented.

# Variants and States

Use for onboarding, tariffs, roaming, entertainment, AI, store, cashback, and product stories. Keep balances, usage, history, security, and settings illustration-free.

# Avoid

- Do not mix unrelated character and object rendering styles inside one card.
- Do not place art behind balance or allowance values.
- Keep yellow as the dominant brand cue.
- If a new subject lacks a reference, match the same friendly 3D volume, soft studio shadow, restrained yellow-black palette, and spacious panel composition so it harmonizes with `ui.md`.
