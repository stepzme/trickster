# Overview

Files supports recent access, shared content, hierarchical browsing, preview, scan, tagging, server connection, and standard file operations.

# Navigation

Recents, Shared, and Browse remain in the primary navigation. Browse uses location titles and back navigation; previews expose contextual actions.

# Core Flows

## Find and manage a file

1. Open a tab or browse a location.
2. Search, sort, or switch list and icon view.
3. Open a file for preview.
4. Use context actions to download, rename, tag, favorite, duplicate, move, share, or delete.

## Add content

1. Choose scan, new folder, or connect to server.
2. Capture or enter required details.
3. Name and save the result.
4. Return to the correct location with the new item visible.

# Interaction Patterns

- Follow platform selection and context-menu conventions.
- Keep current location explicit.
- Preserve aspect ratio in previews.
- Confirm destructive file actions.
- Show local versus cloud availability.

No system-access timing or denial-recovery path was documented in the reviewed source.

# Known Gaps

Unobserved flows, denial paths, cancellation behavior, and recovery states remain unspecified.
