# Overview

t2 uses a glossy, playful 3D object language across services and partner offers.

# Visual Style

Small metallic and translucent objects sit on pastel lime, pink, cyan, or lavender platforms. Forms are chunky, toy-like, and often combine chrome with one saturated detail.

# Composition

Center one object cluster in a rounded tile. Leave a clean label zone and use soft floor shadows rather than complex backgrounds.

# Color

Anchor the system in lime, black, and white, then assign one bright supporting hue per service family.

# Usage

Use for service categories, finance products, subscriptions, gifts, security, and home connectivity. Keep account balances and tariff data free of decorative objects.
