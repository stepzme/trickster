# Overview

Messages is a native conversation system spanning contact discovery, new messages, threaded chat, replies, media, apps, stickers, effects, calls, contact details, and editing.

# Navigation

The conversation list leads into a single chat. Compose stays; contact and call actions remain in the header; app and media tools expand from the composer.

# Core Flows

## Start and continue a conversation

1. Search or create a new message.
2. Select recipients and compose text or media.
3. Send, reply in thread, react, edit, or unsend.
4. Open contact details or start audio/video communication.

## Enrich a message

1. Open camera, photos, audio, apps, stickers, or effects.
2. Create or select content.
3. Preview it in the conversation context.
4. Send and review delivery or read state.

# Interaction Patterns

- Effects temporarily take over the screen without changing the conversation model.
