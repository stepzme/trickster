# Overview

Le Chat is an AI workspace for quick questions, long conversations, research, voice, file and image input, image generation, projects, and subscription upgrades.

# Navigation

The home screen is composer-first. A slide-out sidebar contains search, projects, recent chats, plan status, and New chat; conversation headers expose title and contextual actions.

# Core Flows

## Ask and continue

1. Enter a prompt from the composer and optionally select a mode or attachment.
2. Follow response progress in the conversation.
3. Review the answer, use feedback or utility actions, and continue in the same composer.

## Research and create

1. Enable Research for a sourced, longer-running answer or document output.
2. Generate an image and refine it in the same thread.
3. Group chats in a project or find earlier conversations through sidebar search.
4. Open Pro to compare monthly and yearly limits.

# Interaction Patterns

- The composer remains the primary anchor on home, chats, and projects.
