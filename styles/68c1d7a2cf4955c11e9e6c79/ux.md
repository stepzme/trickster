# Overview

Calendar supports time scanning, event creation, calendar management, search, inbox, and subscriptions through native schedule conventions.

# Navigation

controls move back, open list, search, and add. Today, Calendars, and Inbox remain.

# Core Flows

## Plan an event

1. Choose date and add an event.
2. Enter title and location.
3. Set all-day or start and end times.
4. Configure travel, repeat, calendar, invitees, alert, availability, attachment, URL, and notes.
5. Add and return to the timeline.

## Manage calendars

1. Show, hide, add, recolor, edit, subscribe, or unsubscribe while keeping each calendar identity visible.

# Interaction Patterns

- Snap events to time accurately.
- Keep current time visible.
- Confirm destructive unsubscribe.
