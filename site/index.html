THE DIFFERENCE

AI can write the app.
Trickster makes the process accountable.

It installs a production workflow inside your repository: explicit gates, focused roles, local evidence, and a definition of done that goes beyond a successful compile.

A TYPICAL AGENT RUN

  1. 01 Interpret a loose brief
  2. 02 Choose a look implicitly
  3. 03 Generate many files
  4. 04 Report “build succeeded”

Result: plausible, not proven.

A TRICKSTER RUN

  1. 01 Define scope and acceptance
  2. 02 You confirm one reference package
  3. 03 Build a native vertical flow first
  4. 04 Run, interact, inspect, and accept

Result: a reviewable product.

THE CONTROLLED PIPELINE

Four phases.
No invisible leaps.

Each phase leaves a concrete artifact and a clear decision behind. If evidence is unavailable, the result stays UNVERIFIED.

01

SCOPE / CONTRACT

Shape the product

Turn the brief, repository, and available documentation into explicit boundaries and acceptance checks.

Output → Product contract
02

USER GATE

Confirm one style

Shortlist up to three relevant packages from the curated catalog. You choose exactly one before UI work begins.

Output → Local design source
03

NATIVE IMPLEMENTATION

Build the app

Prove one end-to-end flow, inspect it, then complete the agreed scope with native behavior and accessibility intact.

Output → Xcode project + app icon
04

INDEPENDENT ACCEPTANCE

Verify and deliver

Build, install, run, interact, and visually inspect in Simulator. Only then create store screenshots from real screens.

Output → Evidence + accepted build

NON-NEGOTIABLES

The workflow holds the line.

Constraints are features when the alternative is an impressive-looking result nobody truly checked.

01

One style means one style.

Packages are never merged across screens, and implementation pauses until you select the direction.

02

Native behavior stays native.

Custom appearance must preserve accessibility, focus, keyboard integration, and platform behavior.

03

No self-acceptance.

The implementation owner cannot approve their own work. Evidence is independently reviewed.

04

Unknown stays unknown.

Unavailable tools or missing evidence are labeled UNVERIFIED, never rounded up to success.

QUICK START

Install the factory.

Run Trickster inside an existing Git, Xcode, Swift Package, or XcodeGen project. It installs project-scoped instructions and artifacts—never a global runtime.

Requires macOS · Xcode · Node.js 20+ · iOS Simulator runtime
