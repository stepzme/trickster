# Overview

VK Messenger combines personal and community chats, contacts, voice and video calls, shared media, stories, and account settings in one communication shell.

# Navigation

- Four primary destinations cover Contacts, Calls, Chats, and Account.
- Chat list search, archive, and compose actions sit in the primary navigation.
- A conversation opens into a dedicated context with back navigation, participant actions, and a persistent composer.

# Core Flows

## Find and message someone

1. Search Chats or Contacts, or create a contact.
2. Open a person, community, or favorite thread.
3. Send text, voice, media, files, reactions, or forwarded content.

## Make a call

1. Open Calls or a contact action.
2. Create, schedule, join, or start voice/video directly.
3. Return to history or use the active room controls.

## Organize communication

1. Pin, archive, mute, or select communities for the chat list.
2. Use Favorites and search to retrieve important content.
3. Adjust privacy, notifications, appearance, and call settings in Account.

# Interaction Patterns

- Avatars and presence make dense lists scannable.
- Unread counts and missed calls stay attached to their navigation or list item.
