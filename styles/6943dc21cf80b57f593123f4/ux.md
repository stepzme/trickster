# Overview

Ohmywishes combines personal wishlists, gift discovery, friends, reserved wishes, and Secret Santa games in a light social-shopping experience.

# Navigation

Primary navigation connects Gift Ideas, My Wishlist, Friends, and Secret Santa. Search remains available during discovery, while sharing and account actions stay contextual.

# Core Flows

## Discover and save a gift

1. Browse editorial categories, brands, collections, and product ideas.
2. Open an item for photography, description, price, and purchase destination.
3. Save it to the current wishlist.
4. Return to a photo-led collections where reservation and ownership remain visible.

## Run a Secret Santa game

1. Create a game or open an existing group.
2. Explain rules, add participants, budget, timing, and wish constraints.
3. Invite the group and reveal the assigned recipient when the game begins.
4. Use wishlists to choose a fitting gift without exposing the giver.

# Interaction Patterns

- Editorial collections lead into individual gift items and their purchase destinations.
