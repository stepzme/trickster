# Overview

Glovo supports address-aware discovery across restaurants and stores, filtering, item customization, cart review, payment, courier tracking, order history, and profile tasks.

# Navigation

A four-item primary navigation anchors Home, Discover, Orders, and Profile. The current address stays because it determines the available catalog, timing, and fees.

# Core Flows

## Find and configure an order

1. Choose a service or search, filter merchants, open a restaurant, select a dish, configure required options, and add it to the cart.

## Pay and track

1. Review items, fees, address, timing, and payment, place the order, then follow preparation and courier progress until delivery.

# Interaction Patterns

The sampled flows use direct actions, explicit completion, and return to the current context. No additional repeated interaction behavior was documented.

# System Access Timing

No system-access request timing or denial recovery was documented in the reviewed source.
