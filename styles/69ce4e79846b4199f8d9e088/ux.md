# Overview

(Not Boring) Vibes combines sound, focus intent, and an immersive environment. The user chooses how they want to feel, then adjusts energy, presence, sound, and duration without leaving the scene.

# Navigation

The live scene is primary. A rail changes energy and presence; the vibe tile switches mode. Settings contains guide, achievements, icons, widgets, wallpapers, shop, support, and membership.

# Core Flows

## Start a vibe

1. Choose an intent such as Rise, Focus, Relax, Sleep, or Move.
2. Set energy and presence.
3. Adjust sound if needed.
4. Set a timer or continue without one.
5. Remain in the ambient scene until completion.

## Personalize

1. Settings exposes rhythm, icon, widget, wallpaper, and guide choices without changing the live-session control model.

# Interaction Patterns

- Apply changes immediately to sound and environment.
- Keep session controls at stable screen edges.
- Show timer and selected mode without covering the world.
- Preserve a quick exit from every session.
- Explain premium before presenting system purchase confirmation.
