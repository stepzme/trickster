# Overview

Arc Search is a mobile browser focused on universal search, AI-generated Browse for Me summaries, tab switching, page tools, and concise settings. Browser controls remain available during browsing.

# Navigation

Primary navigation exposes tab overview, new search, and page or menu controls. Search opens modally, and tabs remain directly selectable.

# Core Flows

## Entry and search

1. Complete feature-led onboarding and choose account/default-browser settings.
2. Tap the central plus to open search.
3. Enter a query or use voice, then open a normal result or Browse for Me summary.

## Browse for Me

1. The generated page shows source chips, scanned-page count, a synthesized heading, emoji-led sections, and access to the underlying web result. Sources stay visible so the summary is inspectable.

## Tabs and page tools

1. Tabs use a spatial card stack with recognizable previews. Page menu groups back/forward, URL, link, refresh, find, summarize, pin, share, display, translate, reader, zoom, desktop mode, and site settings.

## Settings

1. Settings groups downloads, archive, site defaults, app icon, search engine, languages, keyboard behavior, archive timing, link handling, privacy, desktop sync, and support.

# Interaction Patterns

- Keep the central search action thumb-reachable.
- Make generated summaries visibly source-backed.
- Preserve page context behind menus and search sheets.
- Use spatial tab previews for recognition.
- Keep browser settings grouped by scope.

# System Access Timing

No system-access timing or denial-recovery behavior was documented in the reviewed source.
