# Overview

Freedom keeps frequent banking actions close to account context while separating promotions from transactional decisions.

# Navigation

Home, Operations, Services, Messages, and More stay persistent; account detail and guided applications use clear back navigation.

# Core Flows

## Manage an account feature

1. Open an account or service card.
2. Review balance, benefits, and eligibility.
3. Change a setting or begin the guided action.
4. Confirm success, failure, or a required offline step.

# Interaction Patterns

- Explain eligibility before requesting data.
- Use one dominant action per step.
- Give failures a direct recovery path.
