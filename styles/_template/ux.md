# Overview

Describe the product's interaction model and what the user repeatedly accomplishes. Do not describe colors, dimensions, typography, shapes, card styling, icon appearance, or visual prominence.

# Navigation

Describe destinations, hierarchy, modal presentation, back/close behavior, and how context is preserved. Do not prescribe how navigation looks.

# Core Flows

## Flow name

1. Describe the observed user action.
2. Describe the state transition or system response.
3. Describe completion and the user's way back.

# Interaction Patterns

Describe repeated behavioral patterns: progressive disclosure, editing, confirmation, cancellation, feedback, recovery, and whether actions are immediate or staged. Keep visual properties in `ui.md`.
