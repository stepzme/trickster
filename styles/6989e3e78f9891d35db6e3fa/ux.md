# Overview

Haptic minimizes the distance between remembering an activity and logging it with a date, rating, and optional note.

# Navigation

The journal or activity overview remains the base layer; selection, logging, customization, and permissions open as focused sheets or system dialogs.

# Core Flows

## Log an activity

1. Choose an activity category.
2. Confirm date and add an optional comment.
3. Set the rating with the bottom control.
4. Save and return to the updated timeline or statistics.

# Interaction Patterns

- Ask for health or media access only when relevant.
- Preserve partial input when a picker or permission closes.

# System Access Timing

No system-access request timing or denial recovery was documented in the reviewed source.
