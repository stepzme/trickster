# Trickster

Эта папка содержит зафиксированную версию переносимого процесса разработки и приёмки iOS-приложения.

- `AGENTS.md` — точка входа для мастера.
- `HARNESS` — имя активного adapter.
- `roles/` — ограниченные контракты фазовых ролей.
- `adapters/` — сопоставление универсальных операций с конкретным harness и последовательный fallback.
- `workflow/master-prompt.md` — порядок отдельных этапов.
- `workflow/orchestration.md` — роли, handoff, владение файлами и Simulator.
- `workflow/scrn-categories.md` — допустимые категории SCRN.
- `workflow/` — scope, референсы, DesignMD, ассеты, реализация, приёмка, app icon, ASO и передача.
- `templates/` — шаблоны артефактов run-id.
- `design/DESIGN.md` — рабочая копия подтверждённого дизайна.
- `artifacts/<run-id>/inputs/` — неизменяемый snapshot входов конкретного запуска.
- `artifacts/<run-id>/` — контракт, референсы, логи, скриншоты и отчёт.
- `runtime/` — локальный launcher DesignMD MCP и зависимости.

Локальные секреты находятся в `.secrets/` и не должны попадать в Git.

Перед проектированием UI мастер обязан завершить SCRN-исследование, выбрать один DesignMD и получить подтверждение пользователя. Для нового приложения app icon создаётся до финальной приёмки сборки, а ASO-комплект — после неё.
