# Overview

Spotify organizes music, podcasts, search, library management, creation, playback, and premium offers around uninterrupted listening.

# Navigation

- Five primary destinations cover Home, Search, Library, Premium, and Create.
- A persistent mini-player remains above navigation while audio is active.
- Album, artist, podcast, playlist, and settings pages use drill-down navigation.

# Core Flows

## Discover and play

1. Browse personalized Home collections or Search categories.
2. Open an artist, album, podcast, or playlist.
3. Start playback and continue through the mini-player or full player.

## Control playback

1. Open the full player from the mini-player.
2. Seek, pause, skip, shuffle, share, view queue, or open lyrics.
3. Return without interrupting playback.

## Build the library

1. Open Library and filter by content type.
2. Search saved content or create a playlist.
3. Edit details, cover art, privacy, and membership actions.

# Interaction Patterns

- The mini-player preserves current media context across destinations.
