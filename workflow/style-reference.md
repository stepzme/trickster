# Этап 3. Выбор пакета стиля

## Цель

Выбрать один проверяемый визуальный и поведенческий язык из локальной базы `trickster/styles/`, подходящий продукту и достаточно конкретный для реализации.

## Состав пакета

Каждый пакет находится в `trickster/styles/<app-id>/` и содержит:

- `source.json` с полями `appId`, `url`, `category`;
- `ui.md` с визуальной системой;
- `ux.md` с навигацией, основными сценариями и паттернами взаимодействия;
- `illustrations.md`, только если у референса есть выраженный иллюстративный язык.

Каталог `_template` не является кандидатом.

## Выбор

1. Прочитай `references.md`, пользовательскую задачу и пакеты релевантной категории.
2. Проверяй, что `source.json`, `ui.md` и `ux.md` существуют и непусты.
3. Сам выбери один пакет по продуктовой задаче, категории SCRN и желаемому характеру интерфейса. Не показывай подборку вариантов.
4. Не выбирай пакет только потому, что его проще реализовать системными компонентами.
5. Наличие или отсутствие `illustrations.md` само по себе не определяет выбор.

Если подходящего полного пакета в локальной базе нет, этап имеет статус `UNVERIFIED`. Не обращайся к случайному каталогу стилей, не создавай пакет по памяти и не переходи молча к стандартному нативному оформлению.

## Обязательное подтверждение пользователя

До проектирования UI сообщи `appId`, URL и категорию; краткий характер стиля; почему он подходит продукту и SCRN-наблюдениям; не менее четырёх конкретных приёмов, которые будут заметны в приложении; существенные платформенные адаптации.

Затем спроси: «Устраивает ли этот референс?» и останови UI-работу до явного ответа.

Если пользователь отклоняет выбор, выбери один новый пакет и повтори подтверждение. Не предлагай несколько параллельных концепций.

## Фиксация после подтверждения

После подтверждения скопируй пакет без изменения содержания в:

```text
trickster/design/source.json
trickster/design/ui.md
trickster/design/ux.md
trickster/design/illustrations.md          # только если есть в пакете

trickster/artifacts/<run-id>/inputs/style/source.json
trickster/artifacts/<run-id>/inputs/style/ui.md
trickster/artifacts/<run-id>/inputs/style/ux.md
trickster/artifacts/<run-id>/inputs/style/illustrations.md  # только если есть
```

Если новый пакет не содержит `illustrations.md`, удали оставшийся от предыдущего выбора рабочий `trickster/design/illustrations.md`. Snapshot внутри run-id неизменяем и является источником конкретного запуска. Подтверждение пользователя фиксируется в `product.md` и `review.md`; `source.json` остаётся минимальным.
