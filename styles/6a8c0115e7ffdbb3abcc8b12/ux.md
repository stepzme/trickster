# Overview

Amie combines calendar and todos in a vertically split workspace. The schedule stays above, task lists stay below, and One control provides navigation, search, resizing, and creation.

# Navigation

Calendar and todo surfaces coexist rather than living in separate tabs. A shared control opens profile, search, calendar selection, and creation; a grabber changes the relative height of the two panes.

# Core Flows

## Onboarding

1. Connect accounts and calendars, answer a short survey, then land directly in the combined day view. Configuration stays lightweight and defers advanced settings.

## Schedule and todos

1. Timed events occupy the day schedule. Inbox and Today lists occupy the lower sheet. Completing a todo moves it into a collapsed done group without removing time context.

## Search

1. Search overlays both panes, keeps the keyboard visible, and filters events and todos together. An empty result uses one quiet explanatory state.

## Profile

1. Profile groups accounts, integrations, appearance, calendars, events, todos, notifications, feedback, Pro, and logout in one settings sheet.

# Interaction Patterns

- Keep schedule and todos visible together.
- Make the pane divider visibly draggable.
- Preserve completed todos in a collapsible group.
- Search across both data types from one field.
