# Overview

Kino.kz is an event discovery and ticketing app spanning cinema, concerts, theatre, family activities, sports, and local venues.

# Navigation

Four primary destinations cover Events, Places, My Tickets, and Profile. City, language, search, and notifications remain in the navigation context; category and date filters sit close to listings.

# Core Flows

## Discover an event

1. Choose a city and browse the mixed home feed.
2. Open the event catalog and select a category.
3. Refine by date or event type.
4. Open an event for details and availability.

## Buy a cinema ticket

1. Review film details and select a session.
2. Choose seats from the seat map.
3. Confirm ticket type, price, and order.
4. Access the ticket from My Tickets.

## Switch appearance

1. Open Profile and theme settings.
2. Choose system, light, or dark appearance.
3. Preserve the same hierarchy and violet selection cues.

# Interaction Patterns

- Filters use progressive browsing.
- Seat selection combines a zoomable map with a fixed price summary and next action.
