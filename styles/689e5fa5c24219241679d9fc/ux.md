# Overview

Yandex Afisha turns city entertainment into a photo-led discovery and ticketing flow. The product moves from editorial event selection to date, venue, seat, payment, ticket storage, and refund.

# Navigation

- A five-item primary navigation separates Home, My tickets, Favorites, Search, and Gift.
- City, date, and event type filters stay above the discovery feed.
- Event pages connect directly to venue, reviews, schedules, and ticket purchase.

# Core Flows

## Discover an event

1. Set city, date, and event type or search directly.
2. Browse hero events and personalized selections.
3. Open a detail page for description, age, place, reviews, and available dates.

## Buy a ticket

1. Choose a date and session.
2. Select colored seats or a price zone on the venue map.
3. Review selected tickets, apply a promo code, and pay.
4. Find the resulting ticket in My tickets.

## Manage plans

1. Save events to Favorites or buy tickets as a gift.
2. Inspect ticket details from My tickets.
3. Start a refund from the ticket context when eligible.
