# Overview

Moonlitt uses a dimensional lunar model and orbital diagram as both the product's data visualization and its expressive visual language.

# Visual Style

The moon is softly textured and luminous, paired with translucent orbital rings, dotted paths, geometric light markers, sparse stars, and violet-blue atmospheric gradients.

# Composition

Center the moon and orbit as the dominant scene. Float controls around the perimeter and preserve clear space along the path for time labels and event markers.

# Color

Use deep navy, indigo, electric violet, moonlit white, and restrained lavender glow. Keep system text white or pale blue.

# Usage

Use the celestial language for onboarding, live exploration, phase summaries, widgets, and live activities. New visuals must remain scientifically legible and harmonize with the UI's glass controls.
