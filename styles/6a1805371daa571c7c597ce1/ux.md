# Overview

Hero's Journey wraps a conventional fitness program in game progression while keeping schedules, tasks, and reports operationally clear.

# Navigation

The home map frames progression; program sheets and detail pages lead to schedule, discipline, tasks, results, and profile.

# Core Flows

## Progress through a program

1. Select or enroll in a program.
2. Review the current level and next workout.
3. Complete attendance and program tasks.
4. Collect rewards and inspect updated progress.

# Interaction Patterns

- Show what action earns each reward.
- Keep fitness metrics distinct from game currency.
- Use sheets to bridge the map and detailed tasks.
- Celebrate rewards without hiding the next step.
