# Overview

Duolingo combines a guided learning path, varied lesson mechanics, streaks, resources, practice, leagues, social activity, and subscription progression.

# Navigation

primary navigation moves among path, practice, leagues, social, profile, and more. Resource counters and the module banner remain above the path.

# Core Flows

## Complete a lesson

1. Choose the active path node.
2. Follow prompt-specific tasks such as choice, typing, listening, or speaking.
3. Receive immediate correct or incorrect feedback.
4. Review explanation when needed.
5. Finish and collect progress, streak, and rewards.

## Continue progression

1. Return to the path with the node updated.
2. Review resource and streak state.
3. Start the next lesson, practice mistakes, or use a boost.

# Interaction Patterns

- Keep one learning decision per screen.
- Make feedback immediate and reversible when appropriate.
- Explain errors without breaking momentum.
- Preserve progress across interruptions.
- Use celebration in proportion to achievement.
