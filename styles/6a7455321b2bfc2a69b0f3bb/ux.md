# Overview

Jomo turns screen-time reduction into a guided routine: set a goal, configure app blocking, then review daily usage and reusable rules.

# Navigation

Four primary destinations cover Home, Rules, Squads, and Profile. The main Start blocking action is repeated from the primary navigation.

# Core Flows

## Set up a goal

1. Establish trust with outcomes and social proof.
2. Collect a name and screen-time baseline.
3. Choose a target with a direct plus/minus control.
4. Continue into blocking setup.

## Start blocking

1. Tap the persistent blocking action.
2. Choose included apps and websites.
3. Configure optional restrictions.
4. Confirm and return to the progress context.

## Create a reusable rule

1. Open Rules and choose a template or create one.
2. Select timing, apps, and exceptions in staged sheets.
3. Review details and activate the rule.

# Interaction Patterns

- The main blocking action remains available across long setup flows.
