# Overview

Trainline has an independently proven illustration layer in the sampled Screen Gallery surfaces: rounded service tiles and onboarding-like education surfaces use flat object artwork alongside real travel photography.

# Visual Style

Illustrations use thick dark outlines, flat mint, cyan, lime, teal, and purple fills, and simple objects such as calendars, stars, locks, tickets, currency marks, search symbols, and help bubbles. The art is friendly and graphic, not glossy 3D, not monochrome line-icon UI, and not stock photography.

When a new illustration is required, create it with an image-generation model from this documented language, review the generated raster candidate, obtain explicit user visual approval, and only then integrate the approved raster asset into the app. The illustrated surface is not design-approved until the approved raster asset is visibly integrated.

# Composition

Use one centered object or compact object group per rounded tile. Keep generous internal padding, a clear silhouette, and minimal internal detail. Larger education compositions may layer a simplified product card over softly cropped travel photography, matching the sampled visual weight and crop.

# Color and Materials

Anchor functional illustration in mint and teal, then use cyan, lime, or purple for one secondary idea. Keep outlines near-black and backgrounds pale enough for text and icon separation. Avoid gradients, glass, glossy 3D materials, and dense scenery.

# Variants and States

Use this language only where the Screen Gallery evidence supports it: service benefit tiles, trust/savings/ticket education, onboarding-like panels, and compact reassurance artwork. Booking forms, timetable rows, conditions, payment-like rows, and account lists remain text-led and should not receive decorative illustration.

# Avoid

Do not introduce an unrelated illustration style. Do not draw or approximate required art with SwiftUI shapes, Canvas, programmatic paths, gradients, SF Symbols, emoji, text glyphs, assembled UI icons, or stock icon packs. Do not integrate an image-generation output before explicit user visual approval; use only the approved raster asset.
