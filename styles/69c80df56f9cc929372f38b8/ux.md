# Overview

Opal turns screen-time control into an immersive focus system with personal score, timer presets, app and website blocking, reusable templates, sleep mode, soundscapes, leaderboard, profile, and settings.

# Navigation

Five destinations connect Focus, Blocks, activity or score, Leaderboard, and Profile. Home keeps duration, blocked apps, and Start Timer.

# Core Flows

## Start a focus session

1. Review Focus Score and choose a timer preset or custom duration.
2. Select apps and websites to block.
3. Start the timer and enter the focused state.
4. Finish or stop with an explicit consequence and updated score.

## Build a recurring block

1. Open Blocks or choose a template such as Work Sprint, Rise & Shine, or Deep Sleep.
2. Select blocked apps, schedule, recurrence, and strictness.
3. Save and show the next activation time.
4. Manage active and upcoming blocks from the list.

# Interaction Patterns

The sampled flows use direct actions, explicit completion, and return to the current context. No additional repeated interaction behavior was documented.
