# Overview

Manus AI is a task-first assistant for prompting, attaching tools, monitoring thinking and progress, reviewing generated artifacts, scheduling work, and managing skills and connectors.

# Navigation

The home screen centers one composer. A task list provides All, Favorites, and Scheduled filters; profile opens as a layered settings sheet.

# Core Flows

## Assign and review a task

1. Choose a model and enter a request in the composer.
2. Add files, tools, voice, or an agent shortcut.
3. Follow thinking, substeps, duration, and generated artifacts.
4. Continue the conversation or open the finished result.

## Manage the workspace

1. Open the task list to find recent, favorite, or scheduled work.
2. Start a new task from the action.
3. Configure knowledge, skills, connectors, integrations, and browser access.
4. Monitor credits and account preferences.

# Interaction Patterns

- Progress remains embedded inside the conversation rather than a separate dashboard.
