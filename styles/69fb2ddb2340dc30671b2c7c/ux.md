# Overview

Tiimo combines daily planning, routines, prioritized to-dos, timers, focus, mood reflection, statistics, learning, and customization.

# Navigation

- A five-part primary navigation provides Today, To-do, Focus, Statistics, and an assistant/profile entry.
- Today uses a date rail and time-of-day groups.
- Tasks open into focused timer and subtask screens without losing the plan.

# Core Flows

## Plan the day

1. Review Today by date and time-of-day group.
2. Add a task, routine, imported calendar item, or suggested breakdown.
3. Set time, duration, priority, visuals, and subtasks.

## Complete and focus

1. Start a task from Today or To-do.
2. Use the timer, pause, add time, or enter Focus.
3. Drag to complete and review streak or trophy feedback.

## Reflect and learn

1. Open Statistics for streak, completed tasks, mood, and learning.
2. Log mood, browse knowledge, or review the day.
3. Adjust themes, fonts, sounds, and app icon in Settings.

# Interaction Patterns

- Serif display headings make planning feel personal and editorial.
