# Overview

Wabi combines a social feed, AI mini-app creation, personal collections, messaging, and profiles in one creator network.

# Navigation

- A five primary destinations moves between Home, Search, Create, Messages, and Profile.
- Home separates personal boards from the broader feed; mini-app actions stay attached to each creation.
- Creation opens a conversational agent first, then exposes draft preview, settings, publishing, and board placement.

# Core Flows

## Discover and use a mini app

1. Enter the feed and open a full-height mini-app card.
2. Interact with the embedded experience, then like, comment, remix, save, or share it.
3. Save useful creations to a personal board or inspect their details.

## Create and publish

1. Start a new Wabi and describe the idea to the agent.
2. Preview and test the generated draft, then edit or undo changes.
3. Configure title, icon, multiplayer, and destination board before publishing.

## Organize and communicate

1. Manage boards and saved mini apps from Home.
2. Search or start a conversation from Messages.
3. Adjust profile, social links, credits, and account settings from Profile.

# Interaction Patterns

- Conversational creation reduces the initial form to a single prompt and reveals configuration later.
