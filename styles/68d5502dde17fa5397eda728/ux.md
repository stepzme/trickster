# Overview

ChatGPT supports conversational work across text, voice, images, files, search, research, study, projects, GPTs, and generated media.

# Navigation

The drawer contains search, ChatGPT, Library, GPTs, projects, recents, and account. Each chat keeps model choice and overflow at the top.

# Core Flows

## Ask and iterate

1. Enter text or choose voice.
2. Attach image or file when needed.
3. Select a specialized tool or model.
4. Submit, follow progress, and stop if needed.
5. Copy, listen, rate, share, or continue the response.

## Research and media

Research and web search expose progress and sources. Image generation keeps prompt, processing, result, selection, edit, save, and share in one thread.

# Interaction Patterns

- Keep send and stop unambiguous.
- Preserve the latest response above the composer.
- Show tool state before submission.
- Attach sources to supported claims.
- Confirm destructive history and account actions.
