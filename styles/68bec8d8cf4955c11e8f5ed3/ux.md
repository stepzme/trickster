# Overview

Clock separates four time utilities into stable tabs and keeps each task native, immediate, and reversible.

# Navigation

World Clock, Alarm, Stopwatch, and Timer are always available in the primary navigation. Add, Edit, Done, Cancel, Save, and Back follow platform placement.

# Core Flows

## Add and manage a world clock

1. Open World Clock and tap Add.
2. Search for a city and select a result.
3. Review city, offset, and current time in the list.
4. Enter Edit to reorder or delete.

## Create an alarm

1. Open Alarm and tap Add or Set Up.
2. Choose time with the wheel picker.
3. Configure repeat, label, sound, and snooze.
4. Save and show the alarm state in the list.

# Interaction Patterns

- Prefer direct manipulation and native controls.
- Show empty states without inventing extra calls to action.
- Preserve live timing state across navigation.
- Announce active alarms and countdown completion accessibly.
