# Overview

Yandex Weather gives a fast answer first, then lets users expand into time, location, risk, and map detail without losing context.

# Navigation

City search changes location; condition items and map shortcuts open focused detail screens with timelines and layer controls.

# Core Flows

## Check a condition in detail

1. Confirm the active city and current forecast.
2. Choose an hourly card, index, or map layer.
3. Inspect time-based values and the legend.
4. Return with city and selected context preserved.

# Interaction Patterns

- Keep current location explicit.
- Synchronize map, timeline, and selected layer.
