# Overview

Pool treats screenshot organization as a workspace: captured items land in one collection, can be opened in place, then grouped into named pools. The product keeps the collection visible and moves editing actions to contextual editing controls.

# Navigation

Primary navigation switches between Home and Pools, while search and add remain available in that context. Settings opens from the account avatar. Detail views provide close, share, overflow, and item actions before returning to the originating list.

# Core Flows

## Onboarding and entry

1. Move the duck to enter, then answer short setup questions in the setup flow.
2. Explain the desired outcome, review a personal screenshot recap, and grant access needed to build the library.
3. Land directly in the screenshot collection.

## Browse and inspect

1. Scan the collection or search within it.
2. Open one screenshot without losing collection context.
3. Add a note, open the source app, crop, share, select text, report a problem, delete, or add the item to a pool.
4. Use multi-select for bulk grouping.

## Pools

1. Switch to Pools and scan cover collages with names and counts.
2. Open a pool, add screenshots, edit its description, or change autopooling.
3. Create a pool through a short bottom-led form; deletion remains an explicit destructive action.

## Settings

1. Adjust account identity, theme, collection density, permissions, trash, analytics, and legal options in grouped system-style rows.

# Interaction Patterns

- Present setup questions sequentially with progress and Skip.
- Keep reversible organization actions close; isolate destructive actions and trash recovery.
