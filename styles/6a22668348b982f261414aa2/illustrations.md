# Overview

Alatau City Bank uses glossy 3D finance objects, oversized metallic numbers, and softly modeled service icons to make a dense banking catalogue approachable.

# Visual Style

Render clean 3D objects with rounded geometry, soft studio lighting, and bright blue, cyan, yellow, green, or violet materials. Promotional numerals may use metallic gold depth.

# Composition

Place one compact object inside a rounded product card or group it with a large rate figure in the hero. Service icons stay centered above concise labels and share a consistent apparent volume.

# Color

Anchor imagery in Alatau blue and yellow. Use green for deposits and success, violet for investments and insurance, and gold only for rate or value emphasis.

# Usage

Use 3D objects for product discovery, service taxonomy, empty states, and confirmations. Use literal card renders and merchant logos when precise financial identity matters.
