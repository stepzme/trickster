# Overview

Joi merges tasks, habits, and meetings into a chronological daily timeline. It prioritizes one-day focus, low-friction capture, and immediate completion feedback.

# Navigation

The day timeline is the default surface. A central add action opens creation; compact edge controls lead to secondary views. A week strip changes days without leaving the timeline.

# Core Flows

## Personalize onboarding

1. Explain the unified timeline.
2. Select goals and starter habits through tappable chips.
3. Confirm the setup and enter the current day.

## Plan a day

1. Select a date from the week strip.
2. Add a task, habit, or event.
3. Set time or recurrence in focused sheets.
4. Save and return to the ordered timeline.

## Complete an item

1. Tap the leading checkbox.
2. Keep the item in place with reduced contrast and strike-through.
3. Update the day summary without interrupting the flow.

# Interaction Patterns

- Week navigation is always visible near the top.
- Creation happens in modal sheets with one decision per step.
- Completed entries remain legible but visually recede.
- Light and dark themes preserve the same monochrome hierarchy and coral day marker.
