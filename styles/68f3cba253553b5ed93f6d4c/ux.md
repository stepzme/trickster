# Overview

Dzen joins personalized media consumption, channel subscription, engagement, creation, studio management, and monetization.

# Navigation

Home, Clips, Create, Video, and Channel remain in primary navigation. Search, notifications, refresh, and channel actions are contextual.

# Core Flows

## Consume and engage

1. Browse the personalized feed.
2. Open article, video, or clip.
3. Like, comment, share, save, or subscribe.
4. Use overflow to block or report when needed.

## Create content

1. Open Create and choose post, clip, article, or video.
2. Add text and media.
3. Configure publication settings.
4. Publish or save the draft when exiting.

# Interaction Patterns

- Keep creator identity attached to content.
- Preserve playback position and feed context.
- Make subscription reversible.
- Confirm draft loss or save.
- Keep moderation actions reachable but secondary.

# System Access Timing

No system-access request timing or denial recovery was documented in the reviewed source.
