# Overview

Yandex Travel moves users from broad inspiration to a precise booking decision while repeatedly surfacing price, timing, and cancellation terms.

# Navigation

Category shortcuts start lodging, apartments, flights, trains, and experiences; deep booking steps use sheets and clear back navigation.

# Core Flows

## Find and book a trip

1. Choose a travel category and destination.
2. Set dates, travelers, and filters.
3. Compare results and inspect details.
4. Review payment and cancellation terms.
5. Book, access documents, or cancel with a stated refund.

# Interaction Patterns

- Keep search state when returning from detail.
- Show price and conditions before the sticky action.
- Explain deferred payment as a timeline.
- Confirm cancellation with refund value and reason.
