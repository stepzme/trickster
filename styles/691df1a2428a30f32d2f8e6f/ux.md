# Overview

An editorial course platform that moves from discovery to structured learning without changing its interaction model.

# Navigation

A persistent four-item primary navigation separates Home, My Courses, Library, and Profile. Home is a curated discovery screen, Library is a filterable catalog, and course details drill into lessons and the player without introducing another primary navigation layer.

# Core Flows

## Account access

1. Open the dark branded entry screen.
2. Enter an email and request a code, or choose account creation.
3. Return to the same shell after access; disabled actions remain visibly subdued until input is valid.

## Discover and start a course

1. Browse editorial course cards and thematic collections.
2. Open a course to see hero media, lecturer, lesson count, duration, and access state.
3. Start the course from the primary action.
4. Watch the lesson in an embedded player, then continue through lesson navigation and key moments.

## Browse the library

1. Search or scan category chips.
2. Adjust sorting and filters from controls above the collections.
3. Open a course for details.

## Get paid access

1. Choose a paid course or subscription entry point.
2. Wait on a branded loading state while the payment page opens.
3. Complete payment in the external provider screen and return to the app.

# Interaction Patterns

- Player controls, lesson navigation, reactions, and key moments remain attached to the learning context.

# System Access Timing

No system-access request timing or denial recovery was documented in the reviewed source.

# Known Gaps

- Permission-denial recovery and unobserved secondary flows were not documented.
