# Overview

Yandex Browser uses soft 3D product symbols and floating interface fragments to explain AI-assisted browsing.

# Visual Style

Build smooth white discs, rounded app symbols, and miniature UI panels with pink-to-coral highlights, soft blur, and restrained depth.

# Composition

Center one paired object or a vertical stack of interface fragments on a pale pink field. Leave generous empty space around the object and avoid busy scenery.

# Color

Use white, blush, hot pink, coral, and small violet accents. Shadows may bloom pink but should remain translucent.

# Usage

Use this language for onboarding and explanations of Alice or browser tools. Keep live pages, search results, and settings as functional UI rather than illustration.
