# Overview

ChallengeUp helps users choose or create challenges, mark daily progress, inspect streaks, share, edit, pause, reset, and finish.

# Navigation

Menu and add sit . The main list holds active challenges; detail contains progress and settings; Other contains guidance and app settings.

# Core Flows

## Start

1. Choose a template by category or create a custom challenge, then set schedule, duration, start date, and notification.

## Complete and manage

1. Tap the dominant done control for today. Detail shows elapsed days, best combo, and successful days; edit supports pause, reset, or deletion.

## Finish and share

1. Completed challenges expose a clear final state and a dedicated progress-sharing action.

# Interaction Patterns

- Make today's completion unmistakable.
- Keep upcoming start dates visible.
- Confirm reset and deletion.
- Preserve progress when paused.
