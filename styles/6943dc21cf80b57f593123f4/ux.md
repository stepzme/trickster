# Overview

Ohmywishes combines personal wishlists, gift discovery, friends, reserved wishes, and Secret Santa games in a light social-shopping experience.

# Navigation

A floating translucent dock connects Gift Ideas, My Wishlist, Friends, and Secret Santa. Search floats just above the dock on discovery screens, while share and menu actions sit around the profile header.

# Core Flows

## Discover and save a gift

1. Browse editorial categories, brands, collections, and product ideas.
2. Open an item for photography, description, price, and purchase destination.
3. Save it to the current wishlist.
4. Return to a photo-led grid where reservation and ownership remain visible.

## Run a Secret Santa game

1. Create a game or open an existing group.
2. Explain rules, add participants, budget, timing, and wish constraints.
3. Invite the group and reveal the assigned recipient when the game begins.
4. Use wishlists to choose a fitting gift without exposing the giver.

# Interaction Patterns

- Product photography and editorial collections carry discovery; UI chrome remains nearly colorless.
- Black full-width actions commit saving, while soft pink-red and blue-purple gradients mark social creation.
- Wishlist counts and categories appear as compact tiles before the image grid.
- The dock stays visually light and emphasizes only the active social destination.
