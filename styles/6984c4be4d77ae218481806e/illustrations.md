# Overview

Fix Price uses a friendly lime hedgehog mascot and playful product props to explain categories, loyalty, seasonal campaigns, and order progress.

# Visual Style

Use softly rendered 3D characters with rounded anatomy, bright lime fur or skin, vivid blue spines, simple faces, and clean toy-like props.

# Composition

Center the mascot or place it to one side of a wide rounded banner, leaving a clear field for short benefit copy.

# Color

Anchor scenes in lime, blue, white, and soft purple, with restrained coral or yellow campaign accents.

# Usage

Use the mascot for onboarding, loyalty, category campaigns, empty states, and order confirmation. Extend the same 3D world for new illustrations so they remain harmonious with `ui.md`.
