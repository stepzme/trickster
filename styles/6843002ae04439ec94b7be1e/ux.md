# Overview

Yandex is a search and assistant super-app spanning text, voice, camera, shopping results, services, and Alice. One universal search context leads into task-specific tools and results.

# Navigation

- The home screen centers universal search and a small set of personalized shortcuts.
- Shortcuts lead to services, mail, weather, profile, and the main menu.
- A restrained primary navigation returns to Home, Alice, and open tabs or results.

# Core Flows

## Search

1. Start from the field with text, voice, or camera.
2. Review results in the appropriate category, such as web, products, images, or answers.
3. Refine through tabs and filters without losing the query.

## Ask Alice

1. Open Alice from the bar or assistant affordance.
2. Choose a suggested capability or write a prompt.
3. Continue conversationally while advanced controls stay secondary.

## Personalize and secure

1. Sign in through Yandex ID.
2. Use Settings for synchronization, data, Alice, search, widgets, privacy, and notifications.
3. Enable biometric access as an optional security step.

# Interaction Patterns

- The universal search bar is the stable anchor across otherwise diverse tools.
- Assistant suggestions show concrete starting points instead of an empty chat.
