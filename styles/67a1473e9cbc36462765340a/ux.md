# Overview

Profi.ru moves from phone-based entry to a service catalog and a highly guided task brief that narrows specialist matching one question at a time.

# Navigation

The observed core does not rely on a dense tab shell. Search and category lists lead into a bottom-sheet-like questionnaire with fixed Back and Next actions.

# Core Flows

## Find a specialist

1. Search or choose a service category, start the task, answer scoped multiple-choice or numeric questions, add requirements, and continue toward matching professionals.

## Sign in

1. Enter a phone number, confirm by SMS, then return to the service-selection or task flow.

# Interaction Patterns

Each screen asks one plain-language question, displays the available specialist count, keeps progress implicit through sequential Next actions, and uses native keyboards only for the relevant answer type.

# System Access Timing

No system-access timing or denial-recovery path was documented in the reviewed source.
