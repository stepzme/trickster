# Overview

Halyk uses compact polished 3D objects in banners and empty states to distinguish services and soften administrative tasks.

# Visual Style

Use clean toy-like objects with rounded geometry, soft shadows, and simple materials rather than character-heavy scenes.

# Composition

Center one object or small cluster on a quiet field, leaving clear space for a short title and action.

# Color

Use Halyk green as the anchor, yellow for insurance, and pale cyan or white backgrounds.

# Usage

Use illustrations for service promotions, onboarding, insurance, and empty states. New art should keep the same compact 3D language and remain harmonious with `ui.md`.
