# Navigation

Orders, Money, Chats, and Profile form the stable shell; during a trip, navigation yields to the route and task modal.

# Core Flows

## Start and review a ride

1. Follow the route to pickup.
2. Verify pickup, destination, timer, and payment method.
3. Call, cancel, or start the trip.
4. Review the order later in earnings comparison or detailed breakdown.

# Interaction Patterns

- Keep the primary trip action reachable with one hand.
- Confirm cancellation separately from calling.
- Explain gross income, fees, and deductions.
- Preserve the selected earnings period and view.
