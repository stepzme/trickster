# Overview

SberBank Online uses soft pastel 3D objects to identify financial products and service categories. The objects support navigation and promotion while balances, transactions, and forms remain illustration-free.

# Visual Style

- Rounded 3D forms with translucent, frosted, or lightly metallic materials.
- Simplified financial symbols such as cards, houses, cars, coins, charts, and wallets.
- Mint and Sber green lead, supported by pale blue, lilac, gray, and small warm accents.
- Diffuse lighting, soft reflections, and shallow shadows.

# Composition

- Use one object or a compact cluster per service tile.
- Anchor the object to a lower or side edge so title and description stay clear.
- Prefer a three-quarter view and recognizable silhouette.
- Keep generous negative space and avoid full narrative scenes.

# Color

- Lead with green or mint on key product objects.
- Use pale neutral materials for supporting mass.
- Reserve brighter colors for small distinctions, never status meaning.
- Keep shadows soft and compatible with the mint canvas.

# Usage

- Use in product discovery, profile benefits, loan types, payment services, and goals.
- Keep transaction rows, receipts, and data-entry forms free of decorative objects.
- Match each object directly to the service it represents.
- Create original assets; do not copy logos, characters, or proprietary object models.
