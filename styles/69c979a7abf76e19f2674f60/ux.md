# Overview

Headspace reduces meditation to a short loop: choose a familiar practice, confirm teacher and duration, then enter a distraction-free player.

# Navigation

Today supports return use, Explore supports discovery, and Profile holds personal state; the player is a focused modal destination.

# Core Flows

## Complete a lesson

1. Choose a recent or recommended practice.
2. Confirm teacher and duration.
3. Start, pause, or seek within playback.
4. Exit or complete and return to Today.

# Interaction Patterns

- Surface recent content before broad discovery.
- Show duration before commitment.
- Keep playback controls sparse and large.
- Preserve progress when a lesson is interrupted.
