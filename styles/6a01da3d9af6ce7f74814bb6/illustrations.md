# Role

Illustration makes Choco's many service verticals quickly recognizable before the user enters a photo-led catalog.

# Visual Language

- Isolated 3D food, groceries, beauty items, travel props, tickets, and activity symbols.
- Soft studio shadows on pale-gray or pastel geometric backgrounds.
- Rounded friendly proportions and clean product-like materials.
- Warm orange, coral, lavender, mint, and cyan accents.

# Composition

Use one compact object cluster per service card with a protected text zone. Category icons should remain centered, simple, and readable at small size.

# Usage

Use for home service cards, category icons, onboarding, and cross-vertical discovery. Use real photography for merchants, dishes, venues, coupons, and products.

# Guardrails

- Do not place 3D objects behind prices, fees, or order state.
- Do not mix illustration and listing photography within one focal card.
- Keep the vertical accent aligned with `ui.md`.
- For a new service, create one small 3D object cluster with soft light, rounded materials, and a pale geometric ground.
