# Overview

Pool treats screenshot organization as a visual workspace: captured items land in one large grid, can be opened in place, then grouped into named pools. The product keeps the collection visible and moves editing actions to translucent edge controls.

# Navigation

A floating bottom control switches between Home and Pools; search and add remain adjacent. Settings opens from the duck avatar. Detail views use a close button at the top, contextual share and overflow actions, and a compact action row at the bottom.

# Core Flows

## Onboarding and entry

1. Move the duck to enter, then answer short setup questions inside a centered sheet.
2. Explain the desired outcome, review a personal screenshot recap, and grant access needed to build the library.
3. Land directly in the screenshot grid.

## Browse and inspect

1. Scan the dense visual grid or search within it.
2. Open one screenshot without losing collection context.
3. Add a note, open the source app, crop, share, select text, report a problem, delete, or add the item to a pool.
4. Use multi-select for bulk grouping.

## Pools

1. Switch to Pools and scan cover collages with names and counts.
2. Open a pool, add screenshots, edit its description, or change autopooling.
3. Create a pool through a short bottom-led form; deletion remains an explicit destructive action.

## Settings

Adjust account identity, theme, grid columns, permissions, trash, analytics, and legal options in grouped system-style rows.

# Interaction Patterns

- Keep the visual collection on screen while controls float above it.
- Use one clear blue bottom action per focused step.
- Present setup questions sequentially with progress and Skip.
- Keep reversible organization actions close; isolate destructive actions and trash recovery.
- Preserve grid density as a user preference rather than a fixed layout.
