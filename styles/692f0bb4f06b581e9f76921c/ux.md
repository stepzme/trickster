# Overview

My Viva is a telecom account app for balance, package allowances, payments, services, roaming, promotions, support, settings, and service-center discovery.

# Navigation

Four primary destinations connect Home, My Account, Special Offers, and More. Home keeps profile, stories, current balance, allowance meters, and service shortcuts in a single path.

# Core Flows

## Monitor and top up the account

1. Review balance and remaining minutes, data, and SMS.
2. Open the active number or package for details.
3. Pay, activate an option, or enter account management.
4. Return with allowance and cost status visible.

## Activate an offer

1. Browse promotional cards from Home or Special Offers.
2. Open an offer and review included services and conditions.
3. Activate through the primary action.
4. Confirm the changed service state.
