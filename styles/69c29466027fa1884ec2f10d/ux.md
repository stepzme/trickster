# Overview

Twinby combines swipe-based dating with compatibility scores, personality tests, conversation cards, likes, chat, and profile verification.

# Navigation

- A five-item bottom bar covers activity or matches, likes, discovery, cards, and profile.
- Discovery centers one full-height profile card with undo, dislike, compatibility, superlike, and like actions.
- Profile holds editing, settings, premium, boosts, superlikes, travel mode, and test history.

# Core Flows

## Create a compatible profile

1. Sign in and add identity, photos, goals, interests, and basic facts.
2. Complete the introductory personality questionnaire.
3. Preview and optionally verify the profile before discovery.

## Discover and match

1. Review a profile card and compatibility score.
2. Swipe or use explicit actions to dislike, like, superlike, or undo.
3. On a match, send a first message or move directly into chat.

## Start a structured conversation

1. Open Cards and select a topic pack.
2. Invite a match or partner to play.
3. Answer prompts together and revisit game history in chat.

# Interaction Patterns

- The profile photo dominates discovery; action circles remain anchored below it.
- Lime compatibility and purple premium signals are distinct from pink match celebrations.
- Tests, cards, and games reduce blank-message anxiety.
- Sensitive profile changes and verification use explicit steps and confirmations.
