# Overview

Yandex Disk uses neon-outline space and media motifs for subscription and storage education.

# Visual Style

Combine simplified video, photo, constellation, and storage symbols with dark silhouettes, electric blue ribbons, mint outlines, and occasional yellow details.

# Composition

Place one compact emblem in the upper-middle of a black screen, followed by a short centered message and a wide action button.

# Color

Use black as the field, deep and electric blue as the main volume, mint for line accents, and yellow for the call to action.

# Usage

Use illustration for onboarding, storage upgrades, and feature explanations. Keep file thumbnails and uploaded media literal.
