# Overview

For Profi connects job discovery, response, chat, balance, portfolio, professional profile, and support.

# Navigation

Orders, Chats, Balance, Profile, and Support remain available; list-map, search, and filters anchor discovery.

# Core Flows

## Respond to a job

1. Search or filter orders.
2. Review scope, budget, date, and client state.
3. Set price and message.
4. Pay response cost when required.
5. Continue in chat and track work state.

# Interaction Patterns

- Keep response cost explicit.
- Preserve filters across detail navigation.
- Link chats to the originating order.
- Confirm complaints and deletion.
