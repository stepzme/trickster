# Overview

A full-screen generative-video social product. The experience moves from atmospheric onboarding into a media-first feed, then uses a compact prompt composer and draft workflow for creation.

# Navigation

A five-item bottom bar covers feed, search, create, notifications, and profile. Creation is the central raised action. Immersive onboarding temporarily removes navigation; publishing and editing use focused full-screen layers with close and overflow actions.

# Core Flows

## Enter the product

1. Continue with an existing ChatGPT identity or choose another account.
2. Review profile presentation and add a profile image.
3. Read the content advisory and begin viewing.

## Browse and respond to video

1. Swipe through full-screen vertical video.
2. Use the right-side rail for likes, comments, reactions, and sharing.
3. Open creator context from the avatar or caption without leaving the media-first hierarchy.

## Create and publish a video

1. Open the central create action.
2. Choose cameos and write a natural-language prompt.
3. Submit generation and review the result in Drafts.
4. Edit the video or caption, then publish.

# Interaction Patterns

- The active media fills nearly the entire screen while controls float above it.
- White pill buttons are used for consequential actions against dark content.
- Creation keeps prompt, cameo choices, and submission in one composer above the keyboard.
- Drafts are represented as large media thumbnails with minimal surrounding chrome.
- Profiles combine creator identity, small counters, outlined actions, and a media grid.
