# Overview

Hero's Journey uses a cohesive game world of isometric maps, buildings, fantasy avatars, chests, and 3D reward objects.

# Visual Style

Use polished stylized 3D with toy-like proportions, crisp silhouettes, vivid gradients, and light fantasy detail.

# Composition

Build navigable routes from isometric landmarks; isolate reward objects against dark radial glows and keep avatars centered in profile scenes.

# Color

Anchor rewards in violet and magenta, maps in sky blue and green, and achievements in metallic gold, silver, or bronze.

# Usage

Use illustrations for maps, levels, characters, rewards, and celebration. New art should extend the same game world and remain harmonious with `ui.md`.
