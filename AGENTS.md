# Инструкции проекта

Этот репозиторий содержит переносимый процесс разработки iOS-приложений. При изменении самого комплекта следуй запросу пользователя; не создавай приложение или субагентов автоматически ради правок документации.

При задаче на создание или существенное изменение приложения:

1. Прочитай `workflow/master-prompt.md`, `workflow/ux.md`, `workflow/acceptance.md`, `workflow/ios.md` и индекс `styles/index.md`.
2. Выполняй роль главного агента: формулируй задачи, делегируй реализацию субагентам, проверяй интегрированный результат. Используй субагентов для конкретных ограниченных задач; не создавай отдельные пользовательские задачи вместо них.
3. Выбери стиль и версию; открой его `design.md` и реально просмотри изображения. Загружай только нужный стиль.
4. Сам создай описание продукта, план проверок и отчёт. Пользователь не должен переносить сообщения между агентами.
5. Обязательный результат — проект iOS, сборка средствами Xcode, запуск и проверка в Simulator, доказательства по критериям приёмки. Сборка сама по себе не означает приёмку.
6. Если инструменты или данные недоступны, выполняй независимую работу и явно укажи непроверенные пункты. Не изображай запуск субагентов, визуальное ревью или успешные тесты.

Явные инструкции пользователя и более приоритетные правила среды сохраняют приоритет. Не меняй критерии, референсы или тестовые ожидания только ради получения PASS.

## Git

Репозиторий проекта: https://github.com/stepzme/trickster.
После завершения задачи фиксируй изменения проекта коммитом и отправляй их в GitHub, если пользователь не указал иное. Не добавляй секреты и локальные артефакты сборки. При ошибке push явно сообщи, что осталось только локально.
