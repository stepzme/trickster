# Overview

Yandex Realty is a listing marketplace that balances image-heavy property search with filters, maps, favorites, chats, and a guided posting flow.

# Navigation

- A five-item primary navigation keeps Home, Search, Favorites, Chats, and Profile available.
- Search results retain query and filter controls and map/save actions .
- Listing detail uses a continuous scroll with a persistent contact action.

# Core Flows

## Find a property

1. Choose buy, rent, new build, or a service from Home.
2. Set location and filters, then scan photo-led result cards.
3. Open a listing, review facts and location, then call, message, or save it.

## Post a listing

1. Choose sale, long-term rent, or short-term rent.
2. Enter location and property attributes in a guided sequence.
3. Add media and details before review and publication.

# Interaction Patterns

- Search chips expose high-value filters without opening the full form.
- Listing details present structured facts in a consistent hierarchy.
- Favorites separate saved listings from saved searches, while chats keep service and human threads together.
