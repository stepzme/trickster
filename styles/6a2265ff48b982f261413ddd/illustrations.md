# Overview

Fresh Screen Gallery evidence shows a recurring Avtoelon.uz authored category-art system on vehicle taxonomy and posting screens: cars, trucks, special equipment, buses, scooters, water transport, tools, and parts appear as clipped object artwork inside pale gray tiles. Use image-generation model output or authored raster assets for this system; do not recreate it with programmatic symbols.

# Visual Style

Render clean semi-realistic vehicle and auto-service objects with soft lighting, simple three-quarter angles, clear silhouettes, and restrained shadows. Artwork should feel like practical marketplace category imagery, not playful stickers or generic app icons. Keep vehicles identifiable by body type, color, and scale.

# Composition

Place the object inside a light gray rounded tile, usually right-aligned or bottom-aligned with a short black label. Larger categories can use wide horizontal tiles; smaller categories can use two-column tiles. Crop only minor edges of the object and preserve the vehicle type. Keep label legibility more important than decorative framing.

# Color and Materials

Use realistic vehicle colors with occasional blue brand emphasis. Tile backgrounds stay pale gray or very light blue-gray. Avoid saturated full-tile color fields except for small source-observed badges. Vehicle glass, wheels, metal, and plastic should be raster-rendered with subtle highlights, not flat vector fills.

# Variants and States

Generate raster assets for marketplace categories, posting category selection, and related empty or placeholder states only after explicit user visual approval. Integrate approved assets as image files in the app bundle and reuse the same visual grammar across all category tiles. Provide size variants that remain crisp in compact grid cells and wide hero-like category tiles.

# Avoid

Do not replace category artwork with SwiftUI shapes, SF Symbols, emoji, line icons, monochrome pictograms, or other programmatic substitutes. Do not use unrelated cartoon mascots, generic car clip art, dark atmospheric renders, or photos where the source pattern calls for clipped authored category artwork.
