# Overview

Flowwow connects local gift discovery, store comparison, configuration, payment, scheduled delivery, tracking, and chat.

# Navigation

Home, Collections, Self-pickup, Inbox, and Cabinet remain stable; search and address anchor discovery.

# Core Flows

## Send a gift

1. Set delivery location and browse stores.
2. Choose a product and review availability.
3. Add postcard, seller note, extras, and discounts.
4. Select delivery time and payment.
5. Track and communicate with store or courier.

# Interaction Patterns

- Preserve recipient and timing context.
- Keep seller quality visible.
- Confirm every optional cost.
- Keep chat linked to the order.
